# Installation

Hey there! Let me guide you through installing **my configs** and introduce you to some basic keybinds!

### 1. Install Git

Make sure Git is installed on your system.

### 2. Clone the repository

```bash
git clone https://github.com/Xijo234/hyprland-configs-pika-arch-nix-compatible.git && cd arch-configs
```

### 3. Run the installer

Choose one of these commands:

**Everything at once:**
```bash
./install.sh
```

**Only configurations:**
```bash
./install.sh --configs-only
```

**Only packages:**
```bash
./install.sh --packages-only
```

### 4. Test before installing

You can test any of the commands above without applying changes by adding `--dry-run` at the end.

Example:

```bash
./install.sh --dry-run
```

### 5. keybinds
apps: 
super return(enter)= open kitty terminal.

super e= open yazi file manager.

super space=open launcher.

super escape=power menu.

super shift escape= btop.

windows:

super 1-0= move to workspace.

super shift 1-0= move window to workspace.

super up/down/left/right= move focus up/down/left/right.

super c= close window.
